# Roadmap dan Backlog

## Fase 0 — Prototype (sekarang)

- [x] Audit paket awal dan Godot.
- [x] Project runnable, landscape, Compatibility renderer.
- [x] Dapur tanpa karakter: lemari, drag, cuci buah, tata meja.
- [x] Jeda dan local save.
- [x] PRD, GDD, kurikulum, arsitektur, smoke test.
- [ ] Playtest sentuh pada dua Android fisik.
- [ ] Perbaiki ikon/narasi berdasarkan observasi.

Exit: anak uji dapat menyelesaikan loop, tanpa blocker, interaksi terasa menyenangkan.

## Fase 1 — Vertical slice berkualitas (4–6 minggu)

Komponen reusable, hint progresif, aset dapur non-karakter, efek nonmusikal, aksesibilitas, Android debug export, test lifecycle, review KIT-01/02/03, panel pendamping, dan timer sesi.

## Fase 2 — MVP rumah (8–12 minggu)

Hub rumah, kamar, halaman, belajar, registry konten, save migration, parent gate. Lalu kamar mandi setelah review, prayer pause manual/terkonfigurasi, narasi/subtitle, localization. Karakter menunggu review fikih/art direction.

## Fase 3 — Premium dan Play (4–6 minggu)

Katalog parent-only, Billing test SKU, purchase/restore/recovery, entitlement offline, AAB, internal/closed test, privacy policy, Data Safety, target audience, rating, listing, dan audit kebijakan terbaru. Tak ada transaksi produksi sebelum sign-off.

## Fase 4 — Rilis terbatas

Rilis bertahap, pantau crash tanpa profiling anak, wawancara keluarga, audit outcome belajar, perbaiki konten/performa. Tambah premium hanya bila bermanfaat dan approved.
