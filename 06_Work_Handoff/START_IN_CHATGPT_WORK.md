# Prompt untuk ChatGPT Work

Saya sedang membangun proyek Android bernama Rumah Rumaysho. Baca SEMUA file di folder proyek ini sebelum mengerjakan apa pun, terutama README, Product Brief, Gameplay, Content Review, Technical Plan, dan Business Plan.

Tugas tahap pertama: audit konsistensi dokumen dan buat Game Design Document (GDD) rinci beserta roadmap MVP dan backlog prioritas. Setelah itu siapkan proyek Godot 4 2D untuk vertical slice Dapur Umma tanpa karakter; jangan membuat gambar karakter dulu. Seluruh aktivitas harus memberi manfaat dunia nyata, memisahkan jam cerita dari jam shalat nyata, dan memprioritaskan keamanan anak serta offline-first.

Jangan menambahkan musik, iklan, chat publik, daily streak, atau mekanisme adiktif. Jangan membuat klaim fatwa otomatis; tandai semua materi agama dan visual yang perlu review ulama. Jangan membuat gambar nabi/sahabat. Rancang premium via Google Play Billing pada fase berikutnya, bukan langsung mengaktifkan transaksi tanpa persetujuan.

Kerjakan bertahap dengan hasil nyata yang dapat diuji, jelaskan file yang dibuat dan cara menjalankannya, jangan mengubah keputusan produk tanpa konfirmasi. Karakter Rumaysho, Ruqoyyah, Maryam, Abati/Zaid, Umma/Yezi direncanakan tetapi asetnya DITUNDA.
